# Data Model: Official Documentation Website

The website has no runtime database. These models are build-time content
contracts.

## DocumentSource

Represents one governed Markdown file approved for publication.

| Field | Type | Rules |
|---|---|---|
| `sourcePath` | repository-relative path | Required, unique, `.md`, must resolve inside repository, must exist |
| `id` | ASCII route ID | Required, unique, begins with `docs/`, lower-case kebab-case segments |
| `description` | string | Required, non-empty, accurate summary used for metadata/search |
| `sidebarLabel` | string | Required, concise Chinese label |
| `group` | enum | `product`, `architecture`, or `development` |
| `order` | positive integer | Unique within group |
| `status` | enum | `established`, `design-target`, or `planned` |
| `editPath` | repository-relative path | Derived from `sourcePath`, never a generated website path |

Validation rejects duplicate sources/IDs, route traversal, missing sources,
missing H1 titles, empty descriptions, and unrecognized status/group values.

## SitePage

The rendered representation of a homepage or published document.

| Field | Type | Rules |
|---|---|---|
| `pathname` | absolute site path | Stable, unique, trailing-slash canonical form |
| `title` | string | Homepage-owned or derived from document H1 |
| `description` | string | Required for metadata |
| `source` | `DocumentSource` or `website` | Identifies governed vs site-specific content |
| `lang` | BCP-47 | `zh-CN` in this feature |
| `contentStatus` | enum | Rendered visibly where maturity could be ambiguous |
| `indexable` | boolean | True for production-ready content; deployment policy remains separate |

## NavigationEntry

| Field | Type | Rules |
|---|---|---|
| `label` | string | Clear, unique within siblings |
| `pathname` | path or HTTPS URL | Must resolve or be an approved external repository URL |
| `group` | enum/optional | Required for documentation sidebar entries |
| `order` | integer | Deterministic ordering |
| `statusBadge` | optional enum | Must not imply delivered product capability |

The sidebar is derived from `DocumentSource`; it is not independently duplicated.

## SearchEntry

Generated by Pagefind from built HTML. It contains route, page title, section
title, excerpt, language, and indexed text. No application-owned search database
or visitor query log exists.

## ContentStatus

Allowed transitions reflect documentation maturity, not Runtime state:

```text
planned -> design-target -> established
```

A reverse transition is allowed only when the source documentation is updated
first. The website never infers product delivery from visual presentation.

## LocaleBoundary

Chinese uses the root route and `zh-CN`. Future locales use a prefixed directory
such as `/en/` and the same document IDs beneath that prefix. Missing locales do
not generate selectors, fallbacks, or placeholder pages in this feature.
